ParaBank Automation Testing Project
Project Overview

This project automates the testing of the ParaBank banking application using Selenium WebDriver with Java.

Technologies Used
Java 21
Selenium WebDriver
TestNG
Maven
Eclipse IDE
Git and GitHub
Jenkins
Test Scenarios
User Registration
User Login
Account Overview
Account Details Validation

Prerequisites
Java JDK 21
Eclipse IDE
Maven
Google Chrome browser
How to Run
Clone or download the project.
Import the project into Eclipse as an Existing Maven Project.
Update Maven dependencies.
Run the TestNG test classes.
View the test results in the TestNG report.
